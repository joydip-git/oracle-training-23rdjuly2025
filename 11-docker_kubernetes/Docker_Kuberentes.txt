Docker:
	a containerization tool
	it helps you create an image based on the app, containing the code of the app, the dependencies, the configuration files etc.
	then based on the image, a container is created to run the app using that image


Scaling up:
	1. purchase more machines and run one copy of your app in every machine.
	2. use VMs. each and every VM will run one copy of your app.

O/S => Core of the O/S (core services are offered - file management APIs)
		 -> Kernel
	at the top of the Kernel other services will be present

docker desktop/rancher desktop for windows

3. docker compose tool 
4. etc.

docker build -t restapp:v1 .
docker images
docker image ls
docker image history restapp:v1

docker run --name restappcontainer -p 4000:3000 restapp:v1
note: by default docker container in run in attached mode

dethatched mode: docker run -d --name restappcontainer -p 4000:3000 restapp:v1

docker start restappcontainer
Note: it starts the container in detatched mode by default

to start in attached mode:
docker start restappcontainer -a

to show the previous logs of the container
docker logs restappcontainer

docker logs restappcontainer --follow (for all logs old+future)
Note: the container will be in attached mode

image is collection of layers about file system instruction
one layer seats at the top of another

remove image: docker rmi restapp:v1

clean up the build cache:
 docker buildx prune -a
